# 文字高亮与阅读模式

2026-09-10：根项目、文脉工坊开源版和 Android 1.1.0 同步提供以下功能。

## 文字高亮

在「小说内容 / 正文」或章节富文本编辑器中，用鼠标拖选文字；手机上长按并拖动选区手柄。点击正文上方的黄色、绿色、蓝色或粉色按钮，即可标记选区。选区可以跨段落。

再次选择已标记的文字可更换颜色；点击橡皮擦可清除所选部分，未选中的部分继续保留。插入和删除正文时，高亮随文字位置调整。

标注自动保存到章节数据库。保存失败时保留本机标注草稿，并显示重试入口。高亮独立于正文，不增加字数，也不会作为 HTML 标签进入 AI 输入或纯文本导出。编辑器与阅读模式共用同一组标注。

## 阅读模式

点击「阅读模式」进入独立阅读界面，点击「返回编辑」退出。

- **目录**：浏览作品的全部章节，搜索章节名并跳转；支持上一章、下一章及空白章节提示。
- **显示**：纸张、日间、护眼、夜间四种主题；字号 14–32、行距 1.4–2.6、宋体/黑体和阅读宽度设置。
- **翻页**：上下滚动或按屏翻页。按屏翻页支持按钮、左右滑动，以及方向键、Page Up / Page Down 和空格键。
- **进度**：拖动本章进度条跳转，退出、重开或刷新后恢复。无已选章节时，优先打开上次阅读的章节。
- **书签**：保存当前位置，浏览书签摘录，点击返回原位置；支持删除书签。
- **沉浸**：右上角进入沉浸阅读，隐藏工具栏；再次点击右上角图标恢复。
- **选文标注**：阅读中同样可以选中文字并添加或清除高亮，正文保持只读。

阅读偏好、进度和书签保存在当前设备；Android 使用原有设备存储桥接，服务端口变化后仍能恢复。Android 返回键先关闭阅读设置/目录等面板，再退出阅读模式。

## 开发与验证

三个前端均持有 `src/features/reading/` 的独立源码副本，构建无需读取其他子项目。

- 根前端与开源前端：`npm run test:reading`；Android：`npm test`。位置计算测试覆盖重叠标注、局部清除、编辑迁移、重复文本、跨段落和 emoji。
- 各后端的 `test_chapter_highlights.py` 使用内存 SQLite 验证持久化、字段校验、作品访问范围和旧数据库重复升级。Android 使用 Python 3.11 及 `runtime/requirements-dev.txt`。
- 在 Android 工程运行 `python scripts/preview-reading.py android`，再运行 `npm run test:reading`，可执行隔离浏览器回归。预览参数可替换为 `root` 或 `opensource`，对应运行 `node scripts/verify-reading.mjs root` 或 `opensource`。

旧数据库启动时会增加 `chapters.highlights` 字段，默认空列表，不重建或删除已有章节。
