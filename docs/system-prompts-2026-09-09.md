# 系统提示词更新（2026-09-09）

根项目的默认提示词已同步到开源桌面版与 Android 运行时。继续使用现有消息模板、配置键、JSON 字段和协议版本，保留各平台原有功能。

## 本次调整

- 正文生成：合并重复规则，统一实际正文、状态快照、已确认设定和章节计划的事实优先级；明确客观事件、角色推测、梦境、传闻及未来计划的区别。
- 长篇连续性：检查人物知识来源、伤势、物品归属、关系和能力代价；落实章节事件与结束状态，避免突然新增规则或提前揭底。
- 续写与打磨：支持从半句中断处接续，按整章累计计算字数；打磨先核实分析证据，保持最小修改、完整返回目标章，不拼入相邻正文。
- 叙事质量：强化人物选择、动作因果、对白目的和场景变化；减少重复心理、模板化转折、设定复述和无关扩写，按题材适配节奏。
- 大纲与 Agent：明确卷数、全书章数、每卷章数和本轮批次范围；保留确认状态及真实 ID，防止重试时重复生成已完成部分。
- 人物与场景导入：修正字段语言冲突，程序字段保留英文键，人物档案内部属性用中文；缺失信息保持未知，推断保留来源，不虚构身世或地理设定。
- 一致性审校：要求可定位证据、严重程度与实际影响相称；把待确认事项与确定错误分开，减少错误建议触发自动改写。
- 结构化输出与有声书：修正大纲优化和语音配置示例中的非法 JSON；明确正文朗读片段不遗漏、不重复、不虚构人物 ID。

## 默认值与自定义设置

未自定义的配置自动采用新版默认提示词。修复了保存过旧默认值后，设置页仍显示旧文本、实际生成却使用新版默认值的不一致。

用户自定义内容继续保留；需要改用新版默认值时，在对应设置项点击“恢复默认”。更新不会自动重置用户自定义内容。旧模板占位符及可配置阶段提示词仍可继续使用。

## 验证范围

完成模板兼容、相关业务回归及静态检查，17 个提示词内 JSON 范例可直接解析。另核对三个源目录中的全部 11 个 Python 提示词模块一致。

未调用真实计费模型，因此这些验证确认的是流程、格式和包内版本，生成内容的实际文风效果仍需结合用户所选模型评估。
